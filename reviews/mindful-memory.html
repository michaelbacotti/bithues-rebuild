Mindful Memory by D. E. Harlan is a practical guide to cognitive maintenance written specifically for an older adult audience. Harlan is careful to distinguish between normal age-related memory changes and the kind of cognitive decline that warrants medical attention—a distinction that many popular books on brain health fail to make clearly.

The book presents a program built around several evidence-based techniques: the method of loci (memory palace), timeline mapping, retrieval practice, and spaced repetition. Each technique is explained in plain language, with specific exercises that can be done without any special materials.

What sets this book apart is its tone. Harlan writes with genuine respect for his readers. There is no condescension, no appeals to fear about cognitive decline as a selling point. Instead, the book is optimistic in a grounded way—the science supports the claim that the brain remains plastic and responsive to deliberate exercise throughout life.

Mindful Memory is most useful as a practical workbook: something to return to regularly rather than read once and set aside.
